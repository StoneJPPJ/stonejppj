Para aplicar no perfil StoneJPPJ:
1. Copie README.md, README.pt-BR.md e a pasta profile-assets para a raiz do repositório StoneJPPJ/stonejppj.
2. Preserve os caminhos dos arquivos. Não basta copiar apenas o texto do README, pois as imagens são locais.
3. A versão em inglês é a principal; o link no topo abre a versão em português.

O README do repositório new-site é a documentação do site e não é o destino deste material.

ANIMAÇÕES

O GIF e PNG de prévia são amostras; o README usa SVGs locais mais leves.
